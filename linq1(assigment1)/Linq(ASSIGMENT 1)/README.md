## ?? Projection Strategy Comparison (Q22)

### Anonymous Types
- ? Fully SQL translatable
- ? No extra definitions needed
- ? Cannot return from methods
- **Best for**: Quick, local projections

### Record Types
- ? SQL translatable with constructor syntax
- ? Immutable by default
- ? Can return from methods
- **Best for**: DTOs, value objects

### Instance ToDto() Method
- ? NOT SQL translatable
- ? Encapsulation - logic with entity
- ? Tight coupling
- **Best for**: Post-query transformations

### Static Mapper Class
- ? NOT SQL translatable
- ? Decouples entities from DTOs
- ? Reusable across contexts
- **Best for**: Clean architecture
